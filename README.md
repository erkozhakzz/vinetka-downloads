### Инструкции по установке

#### Для пользователей Windows
1. Скачайте `VINETKA-Photo-Sorter-Setup-2.2.7.exe` и запустите.
2. При появлении синего экрана Windows SmartScreen:
   - Нажмите **«Подробнее» (More info)**.
   - Нажмите кнопку **«Выполнить в любом случае» (Run anyway)**.
3. Дождитесь завершения установки и запуска программы.

#### Для пользователей macOS
1. Скачайте архив `VINETKA-Photo-Sorter-macOS-arm64.zip` и распакуйте его двойным кликом.
2. Перетащите файл `VINETKA Photo Sorter.app` в папку **«Программы»** (`/Applications`).
3. При первом открытии:
   - Нажмите правой кнопкой мыши (или Control + клик) по приложению `VINETKA Photo Sorter`.
   - В контекстном меню выберите **«Открыть» (Open)**.
   - Подтвердите открытие в системном диалоге macOS.
